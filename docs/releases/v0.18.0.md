# KVMem v0.18.0 · NInfer · Windows RTX 30/40/50

## 中文

将 v0.18.0-ninfer-rc3 的 NInfer Windows 包发布为 0.18.0 正式版。
2026-10-13 更新 Windows 专用、统一及 IQ3/IQ4 源码启动入口：sink 默认 12288 tokens（12K），recent 默认 1024 tokens（1K，16页）。
NInfer 的 recent 最小值仍为 64，保留追加所需的最新页；0–63 会被拒绝。
正式包复用 RC3 的 RTX30/sm86、RTX40/sm89、RTX50/sm120a 引擎和运行依赖，更新启动参数、说明、版本元数据及校验文件。
引擎二进制来源为 938c2f1968b0283e7d7dd143918a9f3ff866dd4d；此次修订更新启动配方、说明与验证，不重编译推理引擎。

## English

Promotes the Windows NInfer RC3 packages to the stable 0.18.0 release.
The 2026-10-13 launcher update sets sink=12288 tokens (12K) and recent=1024 tokens (1K, 16 pages) for dedicated, unified and source IQ3/IQ4 Windows entry points.
The NInfer minimum remains 64; values 0–63 are rejected to protect the newest append page.
The release retains the RC3 engine binaries and dependencies for RTX30/sm86, RTX40/sm89 and RTX50/sm120a, with updated launchers, documentation, release metadata and checksums.
Engine binaries originate from 938c2f1968b0283e7d7dd143918a9f3ff866dd4d; this revision updates launch defaults, documentation and validation without rebuilding the inference engines.
